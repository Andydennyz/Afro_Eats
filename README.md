# Afro Eats

Afro Eats is a modern web application project focused on building a digital food experience around African cuisine.

## Tech Stack

* React 19
* TypeScript
* Vite
* Convex
* TanStack React Query
* Tailwind CSS ecosystem
* Radix UI
* Lucide React
* Hercules authentication and SDK

## Installation

Clone the repository:

```bash
git clone https://github.com/Andydennyz/Afro_Eats.git
```

Navigate into the application:

```bash
cd Afro_Eats/Afro-Eats
```

Install dependencies:

```bash
npm install
```

## Run the Development Server

```bash
npm run dev
```

##  Available Scripts

| Command           | Description                           |
| ----------------- | ------------------------------------- |
| `npm run dev`     | Starts the development server         |
| `npm run build`   | Builds the application for production |
| `npm run lint`    | Runs ESLint                           |
| `npm run preview` | Previews the production build         |

 Project

The main application is located in:
